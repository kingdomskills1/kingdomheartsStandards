# DOCX to TXT

A Windows desktop converter that extracts text and mathematical content from Word DOCX or DOC files into plain text.

## Project Layout

Run the automation from this Code directory. The project files and supporting modules are contained alongside this README.

## Usage

Review the Python entry points in this directory and run the appropriate script or executable from Windows.

## Description

A Windows desktop converter that extracts text and mathematical content from Word DOCX or DOC files into plain text.

## Purpose

Convert Word documents to plain text, including mathematical expressions.
