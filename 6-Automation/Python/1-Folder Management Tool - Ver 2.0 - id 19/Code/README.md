# Folder Management Tool

A Windows desktop utility with tools for printing folder trees, converting file names, deleting items, copying folders, and managing folder contents.

## Project Layout

Run the automation from this Code directory. The project files and supporting modules are contained alongside this README.

## Usage

Review the Python entry points in this directory and run the appropriate script or executable from Windows.

## Differences

Compared with the legacy Folder Management Tool 1.0:

- Reorganizes the application into dedicated Print Folder & File Tree, Delete & Wipe, and Media Converter tabs.
- Adds a Universal Converter for images, videos, video-to-audio conversions, and document conversions.
- Uses separate tab modules for converter, delete, and print-tree behavior.

## Description

A Windows desktop utility with tools for printing folder trees, converting file names, deleting items, copying folders, and managing folder contents.

## Purpose

Organize, print, convert, copy, and delete folder contents.
