# Find and Replace Tool

A Windows desktop Word automation for searching and replacing text across folders and Word documents.

## Project Layout

Run the automation from this Code directory. The project files and supporting modules are contained alongside this README.

## Usage

Review the Python entry points in this directory and run the appropriate script or executable from Windows.

## Differences

Compared with the legacy Find and Replace Tool 1.0:

- Adds separate search result options for all matches, matching files only, and matching file paths only.
- Adds content-type targeting for text, tables, headings, or text plus headings.
- Adds controls for inserting space, new lines, or custom content before or after matched content.
- Adds actions for removing blank lines before or after matched content.
- Updates Word file handling for `.docx` documents and adds default Word heading formatting support.

## Description

A Windows desktop Word automation for searching and replacing text across folders and Word documents.

## Purpose

Find and replace text consistently across Word documents and folders.
